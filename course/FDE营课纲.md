# FDE 行动营（6 周 · 一个人带一支 AI 军团进现场）

CAIO 战略班打得高，一个月碰一次。这个班反过来，打得低，**每周碰一次，重点在做**，直接出东西。

结营那天你手里应该有一样东西：一个真实企业真实签字的交付案例，以及它留下的那套可复用的打法。不是笔记，不是证书。

## 一个人一支军团，不搞配对

以前的版本里我们让工程背景和策略背景的人两两配对。试下来结论很清楚：配对把事情搞复杂了。协作成本、责任模糊、一个人拖累另一个人，这些问题吃掉的时间比配对带来的好处多。

所以现在是个体制。**你一个人领一道真题，从头打到尾**。

一个人怎么打得动一场端到端的企业交付？靠 agent。调研、分析、写代码、跑评估、追进度这些活，全部交给我们提供的 agent 工作流。你的活只剩一件：在每一个判断点上赢。

这不是省人力的说法，是分工线的重新划法。问题弄清楚了，剩下的 AI 基本都能搞定；难的从来是找到真实的问题、真实的 Context、真实的 Eval。那几件事 agent 干不了，所以全部留给你。

## 我们把基建搭好，你只负责判断

进营第一周你会拿到一套 harness 和一组配好的 agent 工作流，直接能用：

| Agent 工作流 | 它替你干的 | 你必须自己赢的那一格 |
|---|---|---|
| 背调 | 企业公开信息、行业链路、竞品、前任 IT 项目的公开痕迹 | 哪条信息是这家公司真正的雷区 |
| 访谈 | 按对象生成提纲、录音转写、抽洞察、标出前后矛盾的地方 | 哪句是真话哪句是客套，对方在护什么 |
| 数据勘查 | 表结构和字段口径盘点、样本抽查、脏数据清单 | 企业方说"数据没问题"时信不信 |
| 造 | 原型、代码、接口、部署脚本 | 这一刀砍下去链路还完不完整 |
| Eval | 评估集抽样、judge 跑批、阈值报告 | 和业务方一起定义什么算好 |
| 采纳陪跑 | 埋点日报（谁用了、卡在哪、谁一次没登录） | 不用的人到底是产品烂、不会用，还是动了谁的奶酪 |
| 结账 | ROI 表算术、汇报一页纸草稿、交付病历草稿 | 这个数字敢不敢当着 CFO 的面讲 |

**项目做成之后需要正经工程化的部分，不用你自己扛**。接系统、权限、稳定性、运维这些，报到我们的支持网络，由网络里的工程方接手，你当接口人。你把事情做成、把判断做对，剩下的系统化我们帮你搞定——这个班要的是能打赢一仗的人，不是全栈。

## 你带什么来

真题。

真题来自 CAIO 战略班的学员企业，也来自我们自己的客户网络。每道题配一个企业方接口人和一个验收人。领题是双向的，你可以挑，题也可以挑你。

自己单位有真题的可以带题进来，前提是同样得配齐接口人、验收人和真实数据授权（见客户准备协议）。

## 六周

### W0 · 领题

- 领真题，签客户准备协议——三样东西不到位就不进 W2
- harness 和 agent 工作流上手，跑通一次完整的背调
- 方法论总览：选造用算全表、三条铁律
- 本周过关：企业背景研究报告 + 进场计划

### W1 到 W4 · 按选造用算跑

四周节拍相同：

- **周一方法课**（2 小时）：本周的方法、判断点讲解、案例库对应案例研讨。案例讲到决策点停下来，全班先作答，再看当事人实际怎么走
- **周中干活**：你在现场或者远程推，agent 做执行，教练一对一各一次
- **周三推进碰头**（1 小时）：这周卡在哪，当场拆。急速把事情推下去是这个班的全部意义，卡三天以上的事必须拿到桌上说
- **周五交付评审**（每人 8 分钟）：讲这周的过关证据

周五这场评审有一条硬规矩：**只看别人的行为证据**。签字的立项书、用户的登录记录、连续使用数据、老板的书面决定——都是别人做出的动作。你自己做的 PPT、你自己写的总结、你自己的感受，一律不算证据。

| 周 | 节拍 | 过关证据（别人的行为） |
|---|---|---|
| W1 | 选 | 企业方负责人签字的一页立项书 |
| W2 | 造 | 真实用户操作 MVD 的记录 |
| W3 | 用 | 目标用户连续 5 天的使用数据 + 一句原话证言 |
| W4 | 算 | 企业方的书面决定（扩大／调整／停止）+ 交付病历 |

真题本身走不通不算你的错。按方法论走到"停止"这个结局、并且写出一份高质量复盘的，照样算过关。烂尾才是唯一的失败。

### W5 · 结营 bootcamp

- 三天冲刺，把四周的东西收敛成一个能当场演示的交付（参照 Palantir AIP Bootcamp 的三段式：陈述、现场跑真系统、被质询）
- 评审团是真题企业的验收人、CAIO 战略班学员、教练组
- **评审只考判断点**：为什么选这个场景、哪个反馈你顶回去了、归因怎么扣的、评估集怎么抽的。操作一律不考，操作是 agent 的事
- 结营时交付病历入库，成为你个人档案的第一页

## 怎么进

申请制，有门槛。看的是你对某个行业有没有切肤之痛，以及你做过最接近"交付"的一件事是什么。

不教 prompt 技巧。结业的标准是企业验收，不是出勤。
