# FDE 实战营课纲（6 周 · 执行层）

**结果承诺：结营那天，你手里有一个真实企业签字验收的交付案例 + 一套能复用的 AI 交付系统（工具箱 + 搭档 + 交付病历）。**

不承诺证书，不承诺就业。这里的"毕业"只有一个定义：真实企业的真实验收。

## 给谁上，怎么进

三类人，两条 track：

- **造 · 工程 track**（对应 Palantir 的 FDSE，内部代号 Delta）：工程师、数据、运维背景，想从写代码转向端到端交付
- **推 · 策略 track**（对应 Deployment Strategist，内部代号 Echo）：售前、产品、项目、业务专家背景——不会写代码不是劣势，你是稀缺的那一半
- 企业派训学员两条 track 都收（CAIO 班学员企业优先）

**申请制**，三关：提交一页申请（你对哪个行业有切肤之痛 + 做过最接近交付的一件事）→ 线上测试（工程 track 考工程判断，策略 track 考场景拆解）→ 15 分钟面试，必问一题："你这辈子为做成一件事拼过最狠的一次是什么？"

丑话前置（报名页原文照登）：不教 prompt 技巧；有淘汰，中途淘汰退还剩余学费；结业标准是企业验收，不是出勤。觉得苛刻的请勿报名——这些原则筛掉的人，正是这个岗位干不了的人。

## 六周结构：1 周预备 + 4 周实战 + 1 周结营

### W0 · 预备周：配对与领题

- 破冰即开工：造推两 track 两两强制配对（组队算法 + 双向选择），签搭档协议（分工、吵架处理机制）
- 领真题：真题来自 CAIO 班学员企业（每题配企业方接口人与验收人），小队与真题双向匹配
- 方法论总览课：选造用算全表 + 三条铁律 + harness 上手
- 本周过关：小队完成真题企业的背景研究，提交进场计划

### W1-W4 · 实战：按选造用算跑真题

四周完全按 [选造用算 30 天交付法](../02-方法论/选造用算-30天交付法.md) 的节拍跑，每周结构相同：

- **周一方法课**（2 小时）：本周方法论 + 判断点讲解 + 案例库对应案例研讨（在决策点停下来全班作答，再看实际走法）
- **周中驻场/远程干活**：AI 做执行（访谈提纲、转写分析、代码生成、报告），人赢判断点；教练每小队每周一次 1v1
- **周五交付评审**：各小队 8 分钟汇报本周过关证据——注意，评审看的是**别人的行为证据**（签字的立项书、用户的登录记录、连续使用数据、老板的决定），不是 PPT

| 周 | 过关证据 |
|---|---|
| W1 选 | 企业方负责人签字的一页立项书 |
| W2 造 | 真实用户操作 MVD 的记录 |
| W3 用 | 目标用户连续 5 天使用数据 + 一句原话证言 |
| W4 算 | 企业方的书面决定（扩大/调整/停止）+ 交付病历 |

淘汰规则：连续两周未过关且无正当归因，劝退（退还剩余学费）。真题本身不可行导致的未过关不算学员责任——按方法论走"停止"结局并写出高质量复盘的，视为过关（烂尾才是唯一的失败）。

### W5 · 结营周：Bootcamp 冲刺 + 放单评审

- 3 天 bootcamp 冲刺：把四周成果收敛成可展示的交付（参照 AIP Bootcamp 三段式：陈述 → 现场演示真系统 → 质询）
- 结营评审团 = 真题企业验收人 + CAIO 班毕业学员（放单考官）+ 教练组
- 评审只考判断点：为什么选这个场景、哪个反馈你顶回去了、归因怎么扣的——操作一律不考
- 通过者进入派单网络（见习级），交付病历自动入库成为个人档案的第一页

## 教练与船长

主教练之外，每期从上一期"过关且真题打出扩大结局"的学员中聘任船长（带教费 + 派单优先权）。第一期由发起团队全员带教。

## 费用与规模

每期 20-30 人（10-15 个小队）。定价对标市场中档训练营，但含真题、驻场支持与结营评审——按"买一个真实案例"理解这笔钱，比按"买一门课"理解更准确。
