# 课程

军火库里的方法论、模板和案例全部免费。这里放的是必须练出来才有用的那部分——怎么用它们带一个人打赢第一仗。

三个班打的高度不一样：

```
   书 + 军火库（免费，立旗和引流）
            ↓
   CAIO 战略班（2 天 + 12 个月月度战略会）
   打得最高，改的是战略和结构，产出真题和生源
            ↓  ↑
 ★ 第一仗三天开局班（3 天）
   最小可售单元，也是最大量产单元。企业内训首选
            ↓  ↑
   FDE 行动营（6 周）
   打得最低最实，跑完选造用算全程，拿到企业验收的交付案例
            ↓
   规培网络（轮转、带教、放单）
```

| 班 | 回答什么问题 | 节奏 | 谁上 |
|---|---|---|---|
| [CAIO 战略班](CAIO班课纲.md) | 我们公司该怎么变、该派谁 | 2 天开班 + 每月半天，共 12 个月 | 创始人、总裁级高管、被点名负责 AI 转型的人 |
| **[第一仗三天开局班](三天班-00-总纲.md)** | 这个人的第一仗打什么、怎么开局 | 3 天 | 作战单元：1 名 FDE 候选人 + 1 名能拍板的负责人 |
| [FDE 行动营](FDE营课纲.md) | 这一仗怎么从头打到尾 | 6 周 | 个体制，一人领一道真题 |

三天班可以独立卖，也可以当作六周行动营的前三天。CAIO 班学员企业派人来上三天班，是最顺的一条通道：老板在 CAIO 班上想清楚了要动哪一处，三天班就把那一处变成一份签字的立项书。

## 三条不动的规矩

1. **每一站的过关标准都是别人的行为，不是你的产出。** 这条也适用于课程本身——三个班都不发满意度问卷，验收指标全部是学员和企业做出的动作。
2. **认证只考判断点，不考操作。** 操作是 agent 的事。哪天开始考操作题，就是体系开始注水的那天。
3. **厂商只能赞助，不能上讲台。** 讲师收厂商的钱，一次即除名。中立性是这些课全部判断的价值来源。
