# 公司文库

这里收录 FDE（Forward Deployed Engineer，前线部署工程师）相关公司的模式分析。每篇按同一个骨架写：一句话定位 → 模式拆解（怎么赚钱、怎么获客、怎么交付或教学）→ 关键数字 → 值得抄的和要警惕的 → 来源链接。海外部分基于一手原典材料（见 `01-原典/`）和公开报道，国内部分基于 2026 年 8 月的一手调研。读的时候建议带着一个问题：这家的模式里，哪一块能搬到你自己的处境里用。
