# 思想家文库

这里收的是理解 FDE（Forward Deployed Engineer，前线部署工程师）这个职业绕不开的 7 个人。每人一份档案：他是谁、他关于 FDE / 交付 / 产品的核心判断（带出处）、这些判断在实际交付工作里怎么用、以及必读材料清单。选人逻辑很简单：前四位来自 Palantir 系——模式的发明人（Sankar）、定调的 CEO（Karp）、最好的记录者（Nabeel）、最清醒的批评者（Barry）；第五位（McGrew）把这套打法翻译到了 AI 时代；后两位（Fitzpatrick、Cagan）不谈 FDE，但 FDE 每天要干的两件事——问出客户的真话、做产品发现——方法论是他们写的。建议按表格顺序读，先立骨架，再补冷水，最后装工具。

| 人物 | 档案 | 一句话 |
|------|------|--------|
| Nabeel Qureshi | [nabeel-qureshi.md](nabeel-qureshi.md) | Palantir 八年 FDE，《Reflections on Palantir》作者，把 FDE 模式是什么、为什么能跑通讲得最透的一手记录者 |
| Alex Karp | [alex-karp.md](alex-karp.md) | Palantir CEO，哲学博士，《The Technological Republic》作者，定义了 FDE 公司该有的气质和该招的人 |
| Shyam Sankar | [shyam-sankar.md](shyam-sankar.md) | Palantir 13 号员工、世界上第一个 FDE，"部署 3 个月内必须用内部工具"规定的作者，《The Primacy of Winning》作者 |
| Barry McCardel | [barry-mccardel.md](barry-mccardel.md) | Hex CEO、前 Palantir，《Understanding Forward Deployed Engineering》作者，专治"学 FDE 学成实施外包"的泼冷水者 |
| Bob McGrew | [bob-mcgrew.md](bob-mcgrew.md) | 前 Palantir 高管、前 OpenAI 研究主管，《The FDE Playbook for AI Startups》演讲者，讲清了 AI 时代 FDE 为什么突然值钱 |
