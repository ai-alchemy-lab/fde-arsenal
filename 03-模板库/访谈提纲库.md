# 访谈提纲库（W1 · 选）

## 权威出处

- The Mom Test 三条规则（Rob Fitzpatrick，2013）。谈他们的生活不谈你的点子；问过去的具体事不问未来的泛泛意见；少说多听。底层论断是"人会出于礼貌撒谎"，所以永远别问"你觉得我这个想法怎么样"。
- Contextual Inquiry 的四原则与师徒模型（Beyer & Holtzblatt，《Contextual Design》，Morgan Kaufmann 1998／第二版 2014）。到现场看真实工作、结成师徒关系而不是问答关系、当场把观察翻译成含义让对方确认、带着明确焦点观察。方法综述公开 PDF：<http://iihm.imag.fr/coutrix/ens/M2-MoSIG-HiL/1stAssignment/ContextualInquiry/holtzblatt.pdf>
- Bob Moesta 的 JTBD 时间线与四力（jobstobedone.org；《Demand-Side Sales 101》，2020）。沿时间线倒着还原"哪一串多米诺骨牌倒下才导致他换"，而不是问他想要什么。<https://jobstobedone.org/radio/unpacking-the-progress-making-forces-diagram/>
- 丰田的现地现物（大野耐一，《Toyota Production System》，1978／英文 1988）。解决问题的唯一正确起点是亲自到发生地去看。

**我们改了什么**

Mom Test 面对的是一个外部客户，内部 FDE 面对的是一张有利益冲突的关系网，所以拆成一线、部门负责人、数据看门人三册分开问——同一句话对一线是求教，对看门人是冒犯。Contextual Inquiry 要几小时的现场 session，内部 FDE 拿不到这个授权，压成一句"上周这个活你是怎么干的，走给我看一遍"。JTBD 的时间线原本还原购买决策，我们改成还原"上一次这事出岔子"和"前任项目的尸体"，那是国内企业最大的雷区图。数据看门人那一组话术和最后的判断点是原版都没有的。

原则来自 The Mom Test：**谈过去不谈未来，挖事实不挖恭维，问具体不问概括**。"你想要什么功能"是废问题——客户说的和做的不一样。

## 好问题十个，进场前背下来

1. 带我走一遍你昨天的工作，从上班到下班。
2. 上一次出质量事故（或者排班冲突、对账对不上）是什么时候，给我讲讲当时的过程。
3. 那次最后花了多少人、多长时间收尾。
4. 这个数从哪来的，你怎么拿到的。
5. 这事现在谁在管，出了问题第一个电话打给谁。
6. 你们试过什么办法解决它，为什么后来不用了。
7. 如果这个问题继续不解决，会怎么样。
8. 整个流程里最让你烦的一步是哪步。
9. 这套 Excel 或系统是谁做的，他还在吗。
10. 除了你，还有谁被这个问题坑得最惨，能引荐我聊聊吗。

## 坏问题十个，全部禁用

| 别问 | 为什么 |
|---|---|
| 你觉得我们这个方案怎么样 | 乞讨恭维 |
| 如果有一个 AI 能自动排班，你会用吗 | 未来式假设，答案永远是会 |
| 你们最大的痛点是什么 | 太抽象，得到排练过的官方答案 |
| 你们想要什么功能 | 把设计外包给用户 |
| 你们是不是经常遇到数据不准的问题 | 诱导性提问 |
| 我们用了最新的大模型，你们感兴趣吗 | 推销 |
| 你觉得这个行业未来会怎么发展 | 聊得很爽，无关 |
| 领导，您对数字化转型有什么规划 | 引出 PPT 语言 |
| 所以你的意思是这个方案可行，对吧 | 逼对方给承诺 |
| 这个需求优先级高不高 | 所有需求的答案都是高 |

## 三册话术

内部 FDE 面对的不是一个客户，是一张有利益冲突的关系网。同一句话对一线是求教，对看门人是冒犯，所以必须分册。为什么必须分册的两个反向例子，见 [第 6 章第九节](../book/第06章-真问题与Context.md)。

第一册对一线操作者，目标是 L1 加 L2。开场用师徒话术。主问"上周这个活你是怎么干的，走给我看一遍"。挖例外用"一般是这样，但是如果……什么情况下会不一样"。挖判断用"你刚才怎么知道要选这个的"。挖变通用"有没有什么活，系统里不好办，你自己有一套办法的"，这句要在建立信任之后再问，太早问会被理解成查违规。收尾用"我明天还来，你有什么要我带的"，下次还能来，比这次问到什么更重要。

第二册对部门负责人，目标是 L3 加拍板承诺。开场"我想先跟您对一下这件事该怎么算成功"。主问"如果这件事做成了，您手上哪个数字会变"。挖约束用"这件事做成了，您这边会不会有人不高兴"，这句能问出来的都是宝贵信息，问不出来说明信任还不够。挖尸体用"以前有没有人试过，后来怎么样了"。要承诺用"我需要每周两小时您或者您指的人陪我，第四周的验收会您需要在场，这个能定下来吗"，要具体的时间，不要"支持"这个词。

第三册对数据看门人，目标是 L4。上一节整节都是这一册，不重复。只补一句顺序，先给地位，再挖坑，再给交换，最后要日期，这四步的顺序不能换。


## 访谈纪律

- 录音（征得同意），AI 转写和抽取洞察，你的注意力全部留给追问
- 每场访谈后 10 分钟内记下三件事：最意外的一句话、说的和做的不一致之处、下一个该访谈的人
- ⚠️ **人的判断点**：哪句是真话哪句是客套；对方护着什么、怕什么。AI 抽取不了屋子里的空气。
