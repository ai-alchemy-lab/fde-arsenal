# 模板库

选造用算 30 天交付法的配套模板，12 件，全部免费，商用注明出处即可。

**除内部 AI 落地项目授权书外，每一件都站在一个有名有姓的祖先身上**（那一件无外部祖先，是原创，理由写在它自己的「权威出处」一节里）。每个文件开头都有一节「权威出处」，写清原版是谁的、原版核心结构长什么样、我们改了哪几处、为什么这么改。查得到的链接都给了，查不到确切一手出处的东西我们不写。

**用法提醒**：每个模板里都标了「人的判断点」——模板能让 agent 帮你把八成的执行做掉，判断点必须自己赢。填得再漂亮的表，救不了判断点上的偷懒。
