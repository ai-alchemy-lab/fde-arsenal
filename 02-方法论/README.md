## 支撑方法论（五篇）

- **[MVD 最小可行部署](mvd-最小可行部署.md)** — 治"95% 的 AI pilot 上不了生产"的病：与 MVP/POC 的裁判之别、三条军规（真实数据 / 缩小范围不缩小价值 / 锁死期限）、两周冲刺逐日排法、客户侧三要素、"读旧写新顺人"进场原则。
- **[AIP Bootcamp 模式](aip-bootcamp-模式.md)** — Palantir 把销售动作做成交付动作的获客机器：六条设计原则、三段式议程、客户准备协议、11 类用例题库、单季 660 场的转化数据，以及在中国落地要改的五件事。
- **[Mom Test 访谈法](mom-test-访谈法.md)** — FDE 进场调研怎么问出真话：为什么"你想要什么"是废问题、谈过去不谈未来、挖事实不挖恭维，附 FDE 场景 10 个好问题与 10 个坏问题对照清单。
- **[Echo-Delta 配对](echo-delta-配对.md)** — 双角色作战：FDSE 管造、Deployment Strategist 管推，各自的能力面与面试考法、项目里的接力配合、边界模糊地带的处理规矩，以及为什么中国市场 DS 型人才更稀缺。
- **[认证模式对比](认证模式对比.md)** — 全球五种 FDE 培养模式对比表（Supervity 选拔输送 / ADaSci CFDE 自学认证 / 工信部证书系 / Maven cohort / 医师规培式），各自的能力信号强度与适配的市场阶段。
