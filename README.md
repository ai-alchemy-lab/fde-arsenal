# FDE 军火库

**中文世界的 Forward Deployed Engineer 开源知识库：方法论、模板、案例、原典，每周更新。**

---

## 为什么有这个库

两个数字放在一起看：

- FDE 岗位数量一年涨了约 7 倍（2025.4 → 2026.4，全球招聘数据），上海市政府已经把"培育前沿部署工程师（FDE）队伍"写进了三年行动方案；
- 与此同时，95% 的企业 AI 项目对损益没有产生可量化的影响（MIT NANDA，2025）。

一边是最抢手的新岗位，一边是九成半的项目白干。中间缺的不是资讯——关于 FDE 的文章已经泛滥了——缺的是**能落地的方法、能直接用的模板、和能训练判断力的真实案例**。这个库只放这三样东西。

一句话说清 FDE 是干什么的：企业买了 AI 却用不起来，FDE 就是进到现场、把 AI 变成业务结果的那个人。不是咨询顾问（顾问交付报告就走），不是外包（外包只管做完不管有用），是**对业务指标负责的人**。

## 核心方法论：选·造·用·算

30 天，四周，每周赢一件事。完整手册见 [02-方法论/选造用算-30天交付法.md](02-方法论/选造用算-30天交付法.md)。

| 周 | 一个字 | 要赢什么 | 过关标准 |
|---|---|---|---|
| W1 | 选 | 找到值得打的仗，拿到进场授权 | 老板在一页立项书上签字 |
| W2 | 造 | 真实数据跑通端到端 MVD | 真实用户第一次上手 |
| W3 | 用 | 让一线真的用起来 | 目标用户连用 5 天，说出"有用" |
| W4 | 算 | 算清账，拿到下一步决定 | 老板拍板：扩大 / 调整 / 停止 |

注意过关标准的写法：**全部是别人的行为，不是你的产出。** 自己觉得做完了，不算完。

## 开源边界

这个库的原则是：**能写下来的，全部免费开源；必须练出来的，才值得付费。**

方法论、模板、案例、导读——全在这里，不设任何门槛，商用请注明出处。判断力的训练（真实企业、真实死线、真人验收）不是读文档能获得的，那是训练营和实战网络的事，与本库无关。

## 如何贡献

最欢迎的贡献是**真实交付案例**（按 [04-案例库/README](04-案例库/README.md) 的格式，需脱敏）。其次是模板改进、导读补充、情报线索。规则见 [CONTRIBUTING.md](CONTRIBUTING.md)。

丑话说在前面：本库不收三类东西——课程广告、未经验证的"方法论"、和任何形式的成功学。有争议的内容以"是否帮到明天要进客户现场的人"为唯一裁判标准。
